# homebrew-tap

Homebrew formulae for [cristiansteib](https://github.com/cristiansteib)'s tools.

```sh
brew tap cristiansteib/tap
brew install multiversectl
```

| Formula | What it is |
|---|---|
| [`multiversectl`](https://github.com/cristiansteib/multiversectl) | Run several complete copies of a multi-repository project side by side on one machine. |

The formulae here are written by [GoReleaser](https://goreleaser.com) when a
release is published; edit the project, not this repository.
